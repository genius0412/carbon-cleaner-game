# Team photos

Drop each member's photo in **this folder** with these exact filenames (used by
`app/team/page.tsx`):

- `dohun-kim.jpg`
- `raymond-kwok.jpg`
- `arnie-sreeram.jpg`

Square images work best (they're shown in a 96×96 circle, cropped to cover).
If your files are PNG instead of JPG, either save/export them as `.jpg`, or
update the `photo:` paths in `app/team/page.tsx` to match the extension.
